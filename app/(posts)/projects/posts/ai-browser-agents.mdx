AI Browser Agents lets people describe browser tasks and monitor the work as an agent carries them out in a local Chrome session.

## Highlights

- Combines a Next.js interface with a FastAPI service.
- Uses Chrome through the browser’s local debugging connection.
- Shows task status and history in real time.
- Supports vision-based actions and multiple language model providers.
