Look Away is a native macOS app that helps people build healthier screen habits while they work.

## Highlights

- Sends adjustable reminders to fix posture and blink.
- Locks the screen at set intervals for distance-focused eye breaks.
- Uses macOS accessibility features instead of a web wrapper.
- Keeps the reminder and break settings adjustable.
