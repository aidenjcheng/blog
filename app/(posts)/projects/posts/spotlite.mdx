Spotlite is a native macOS Spotify client with a SwiftUI interface and local playback through Spotify’s Web Playback SDK.

## Highlights

- Uses OAuth PKCE with Keychain token storage.
- Supports search, liked songs, playlists, albums, and artists.
- Includes a now-playing bar, queue, volume controls, and keyboard shortcuts.
- Keeps the app native and uses a hidden `WKWebView` only for Spotify playback.
